# 2026-10-15

## P36.3.1 split: the census and the database are 36.3.2

36.3.1 bundled three reshapes ([2026-10-14](2026-10-14.md), "P36.3 split").
Making the statistics' view-interpreted fields private changes no persisted
byte. The census as one field and the database stored once both change the
cache's format, and the second reaches every `block.database` read in four
crates. Their reviews differ: one is an API narrowing the compiler checks,
the other a format change with a `CACHE_FORMAT_VERSION` bump
(`docs/process.md`, "Slice numbering").

So 36.3.1 is now the statistics fields, landed and ticked
([notes](../../design/roadmap-P36.3.1-statistics-views-notes.md)). 36.3.2
holds the census, the database and the bump, and comes before 36.4.
