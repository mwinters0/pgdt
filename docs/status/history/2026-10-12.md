# 2026-10-12

## P35's spec: no module loads by `#[path]`, tests included

35.26 made `layering.py` refuse `#[path]` in a test's sources as well as a
library's, past what the spec asked. The maintainer affirmed it: `check.py
--affected` finds a test's files by its `mod` lines, so a test loading one by
path would be checked blind. The spec's "The crate graph" now says so, and the
reason is D68's Rejected line.
