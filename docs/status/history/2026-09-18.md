## `M116`: `pgdq info` takes `--strict-identity`, and the flag means one thing everywhere

Reviewed under STATUS's "Decisions worth another look", where 14.3 filed the
call that `info` should not carry the flag. The entry is closed, the answer went
the other way, and the flag landed: **it has one meaning on every command**, so
`pgdq info --strict-identity=time --source X` refuses a cache whose bound signal
has moved, exactly as `parse` and `query` do.

The slice's reasoning was that a refusing `info` would remove the one command
that can say why the others stopped. **That mistakes a refusal for a silence.**
`Error::StrictIdentityUnmet` names the cache, the term that bound and the clause
that failed, so the refusal *is* the explanation, and the flag being **opt-in**
leaves the advisory report one omission away — against a command-shaped
exception to what D5 describes as one question asked of every provider.

The comparison moved out to `CacheMode::strict_identity_refusal`, which both
callers ask — the library still owning it, which is D5's own reason for putting
the selection on `CacheMode`.

**Cache-only `info` is a usage error, not a refusal.** With no `--source` the
identity is *null* rather than absent, and D5's "absence is a failure" never
reached it: absence is a source that exists and cannot answer, while asking for
a guarantee about a source nobody named is malformed. clap's
`requires = "source"` answers it before anything is opened.

## `M113`: the statistics allowance's two lines are pinned, and the decline test is off one

`statistics_allowance`'s floor is not `margin_allowance`'s, and neither of its
lines had a test. Both are pinned now, in `pgdump_query/src/io.rs` by
`statistics_are_starved_below_their_own_line_and_unfloored_above_the_crossover`:
the **zero line**, `MEMORY_UNPOOLED_BOUND × 100 / (100 − MEMORY_MARGIN_PERCENT)`,
at and below which the margin ceiling is zero whatever the budget; and the
**cap/ceiling swap** at `5 × (MEMORY_RESERVE − MEMORY_UNPOOLED_BOUND)`, below
which `ceiling − cap` survives every per-worker charge and above which a source
whose step divides the ceiling leaves the statistics nothing

would have noticed one of those three constants moving past another.

The decline test in `pgdump_query-cli/tests/statistics.rs` sat on the zero line
exactly, where an integer division's rounding decided the run it asserts on; it
now sits inside the band and cites the unit test.

## D1's cold-walk remedy is the straddling window; the stride was refuted

`xz-seek`'s `9.1` measured the stride speculation D1 named and confirmed none of
its guesses, so the remedy is now the straddling window and the residual — one
fetch a stream — a floor on a file with no stride
([`../../design/roadmap-P14-remote-input.md`](../../design/roadmap-P14-remote-input.md),
"D1"). Two things that entry does not carry:

**Do not re-propose a sampled `first_block_dict_size`.** Put to `xz-seek` here
as a way to delete the per-stream header read, and withdrawn: the miss is
whichever request first *opens* a boundary, so dropping the header moves it onto
the padding probe rather than removing it — bytes saved, and this walk's cost is
round trips. And `9.3` will publish the straddle's residual misses by request
kind, which tests that floor rather than deciding anything of ours: ~one miss a
stream, and materially above that falsifies it.

## A cancelled read is the interrupt by another door, and `14.9` is that slice

One predicate, not a rework of every read loop — that would break `query`,
which errors on cancellation on both providers by design. **D26 now reads
command-shaped, not run-shaped**, reviewed after the slice landed: the exit code
is all a script reads, so keying it on what a run banked makes a Ctrl-C a race.

**`M121` corrects three things the slice left.** The prepass arm's `cache.save`
goes: reached only with nothing banked, it writes a map describing zero bytes
or strips an existing empty one's identity diagnostics, and can then refuse a
resume through `SourceChanged`. `parse`'s interrupt line gains a nothing-banked
branch naming no file — "continue" is wrong with nothing to continue from. And
both `cancelled_read` arms call `watch.check(source)` themselves rather than
inheriting it from the save, closing a gap older than the slice: over
`--dqcache none` the save is a no-op, so an interrupted run never verified the
source stayed put, where the polled path always did.
