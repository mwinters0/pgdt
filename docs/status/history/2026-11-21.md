## The observer contract splits in 43.6

- **The maintainer reversed 43.5's one-trait call**, so 43.6 splits `BlockObserver` into a row trait and a block one,
  and makes the `Recorder` generic over its observer (`../../design/roadmap-P43-block-model.md`, "One recorder, a held
  row split once"). The reason: a one-type `Recorder` carries the piece's panicking `close` up a level, to the piece
  recorder's own `finish`. Only the interior host makes pieces (`interior.rs`), and it uses each one only for rows,
  then absorbs it.
