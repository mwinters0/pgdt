## The P36 wrap's code findings admitted as `M230`–`M232`

The repoint opening P36's wrap (`b832ca4e`) found three claims only a code
change corrects, filed as `KD124`, `KD125` and `KD126`. None is P36's: each
predates it, the repoint's read being what met them. Grilled with the
maintainer and admitted, each an empty `Blocks`, no phase being open
([`../../design/out-of-band.md`](../../design/out-of-band.md)):

- **`M230`** closes `KD124` and `KD52` together. Both are `strip_ci_suffix`
  falling short of the boundary rule `docs/design/decisions.md`, "D60" states
  for every keyword, so the worded operators are matched as words —
  case-insensitively, any whitespace between them, a boundary before `is` —
  and the byte cut that panics on `日本語` goes with the literal suffix.
  Refused: `s.get(split..)` alone, which mends the panic and leaves the
  grammar D60 already refuses.
- **`M231`** closes `KD125`: the warning says several round trips per stream,
  the manual's own word (`docs/manual/dump-inspection.md`). Refused: "four",
  a count in a string that `KD36`'s straddling window falsifies unseen; and
  any wording survives `KD36` closing, so its marker in `xz.rs` gains a line
  naming the warning and the manual's sentence as the copies its closure
  rewrites.
- **`M232`** closes `KD126`: `TilingBroken`'s message tallies its issues by
  kind, a `Discontinuity` a gap or an overlap by whether `next_start` is past
  `span_end`, kinds with none left out. Refused: one generic count, which
  names nothing a report needs; the first issue's offsets, which a one-line
  diagnostic carries badly and the serialized `issues` already hold.

## `M230` lands: the `IS` tests are words

`is_test` in `crates/pgdt/src/query/filter/term.rs` reads a term with no
operator from its end, word by word at ASCII whitespace, in place of
`strip_ci_suffix`'s byte cut; `KD52` and `KD124` are struck with it. A
column is now required before `IS`, so `--filter 'is null'` takes the usage
message where it named the column `''`, matching `distinct_from_at`'s refusal
of a phrase at the term's start. A quoted column touching `IS`
(`"x"is null`) is refused likewise, as `"x"is distinct from y` already was.
Tests: `the_is_forms_are_matched_as_words`,
`a_multi_byte_term_with_no_operator_is_a_usage_fault`.

## `M231` lands: the walk's warning says several round trips

`announce_remote_walk` in `crates/pgdt-io/src/source/remote.rs` says "several
round trips per stream", the manual's wording; `KD125` is struck with its
marker. `KD36`'s marker in `crates/pgdt-io/src/source/xz.rs` names the warning
and `docs/manual/dump-inspection.md`, "Reading a dump over HTTP" as the copies
its closure rewrites. The assertion message in
`crates/pgdt/tests/http_conformance.rs` took the same word. Test:
`parse_over_a_remote_xz_announces_the_walk_before_paying_for_it`.

## `M232` lands: a tiling failure is tallied by kind

`tiling_tally` in `crates/pgdt-model/src/diagnostic.rs` builds
`TilingBroken`'s message: gaps, overlaps and spans out of order counted, a map
not starting at byte 0 or not ending where the scan did named without a count
(`check_tiling` raises each at most once), empty spans counted, in
`TilingIssue`'s order, kinds with none left out. `KD126` is struck with its
marker. Test: `a_tiling_failure_names_each_kind_it_counts`, in
`crates/pgdt-model/src/diagnostic/tests.rs`.
