## The P36 wrap's code findings admitted as `M230`–`M232`

The repoint opening P36's wrap (`b832ca4e`) found three claims only a code
change corrects, filed as `KD124`, `KD125` and `KD126`. None is P36's: each
predates it, the repoint's read being what met them. Grilled with the
maintainer and admitted, each an empty `Blocks`, no phase being open
([`../../design/out-of-band.md`](../../design/out-of-band.md)):

- **`M230`** closes `KD124` and `KD52` together. Both are `strip_ci_suffix`
  falling short of the boundary rule `docs/design/decisions.md`, "D60" states
  for every keyword, so the worded operators are matched as words —
  case-insensitively, any whitespace between them, a boundary before `is` —
  and the byte cut that panics on `日本語` goes with the literal suffix.
  Refused: `s.get(split..)` alone, which mends the panic and leaves the
  grammar D60 already refuses.
- **`M231`** closes `KD125`: the warning says several round trips per stream,
  the manual's own word (`docs/manual/dump-inspection.md`). Refused: "four",
  a count in a string that `KD36`'s straddling window falsifies unseen; and
  any wording survives `KD36` closing, so its marker in `xz.rs` gains a line
  naming the warning and the manual's sentence as the copies its closure
  rewrites.
- **`M232`** closes `KD126`: `TilingBroken`'s message tallies its issues by
  kind, a `Discontinuity` a gap or an overlap by whether `next_start` is past
  `span_end`, kinds with none left out. Refused: one generic count, which
  names nothing a report needs; the first issue's offsets, which a one-line
  diagnostic carries badly and the serialized `issues` already hold.

## `M230` lands: the `IS` tests are words

`is_test` in `crates/pgdt/src/query/filter/term.rs` reads a term with no
operator from its end, word by word at ASCII whitespace, in place of
`strip_ci_suffix`'s byte cut; `KD52` and `KD124` are struck with it. A
column is now required before `IS`, so `--filter 'is null'` takes the usage
message where it named the column `''`, matching `distinct_from_at`'s refusal
of a phrase at the term's start. A quoted column touching `IS`
(`"x"is null`) is refused likewise, as `"x"is distinct from y` already was.
Tests: `the_is_forms_are_matched_as_words`,
`a_multi_byte_term_with_no_operator_is_a_usage_fault`.

## `KD58`, `KD114`, `KD47` and `KD46` admitted as `M233`–`M236`

Four `(c) unowned` entries whose fixes fit a session, grilled with the
maintainer between phases and admitted, each an empty `Blocks`, no phase
being open ([`../../design/out-of-band.md`](../../design/out-of-band.md)).
Each lands as its own commit.

- **`M233`** closes `KD58`. Three sites compute an index's derived
  diagnostics — `build_index` (`crates/pgdt-mapping/src/whole_file.rs`),
  `status_from_file` (`crates/pgdt-dump/src/cache/store.rs`) and
  `map_file_watched` — and only the last leaves out
  `non_seekable_compression_diagnostic`. One function beside the three it
  calls in `crates/pgdt-dump/src/map/tiling.rs` computes them from an index's
  spans, size and seek table, and all three sites call it,
  `map_file_watched` keeping its `carried` cache diagnostics ahead of it.
  `DumpIndex::diagnostics` is `#[serde(skip)]`, so no cache format moves.
  Refused: the one missing line alone, which mends the symptom and keeps three
  copies to drift.
- **`M234`** closes `KD114`. `_printTocEntry()` writes `Owner: %s` from
  `sanitize_line(owner, true)`, so a NULL owner is `-` and an empty one is
  nothing, the line ending `; Owner: ` — every 16–18 fixture holding a
  `COMMENT ON EXTENSION` has one. `step` hands `parse_toc_header_line` the
  line with only its terminator and leading whitespace removed, so every field
  reads what `pg_dump` wrote: an empty owner is `None` as `-` is, and an owner
  or tablespace name ending in whitespace reaches `DumpIndex::roles` and
  `tablespaces` whole through `harvest_toc_cross_refs`, where `line.trim()`
  clipped it. `looks_like_toc_name_line` keeps the trimmed line. A
  `CACHE_FORMAT_VERSION` bump, `TocHeader` being persisted. Refused: splitting
  on `"; Owner:"` in the parser, which still clips such a name.
- **`M235`** closes `KD47`. A truncated lower bound is a prefix below every
  value of its group and a truncated upper bound a successor above every one
  (`Bounds`, `crates/pgdt-model/src/statistics.rs`), so where the two share
  their text the exact one is the column's extreme. `ColumnExtremes::fold`
  replaces a held truncated bound by an exact one on an `order_key` tie, and
  otherwise keeps the first as now; only `text`, `character` and `bytea`
  truncate, and for those a key tie is a text tie. Tested on `fold` itself, the
  two bounds in either order, no dump fixture reaching one.
- **`M236`** closes `KD46`. The gatherer's `RowOrder` knows a block holding at
  most one distinct non-NULL value — `never_decreased` and `never_increased`
  both hold — and now reports it as `Sortedness::Constant`, `Sortedness`'s doc
  losing the "is `Ascending`" convention. `column_order` takes it as setting no
  direction; where no block sets one, the blocks' edges are checked ascending,
  then descending, the first holding declared and neither declaring nothing,
  so a single constant block declares `Ascending` as today (DataFusion keeps
  one ordering a column, `output_orderings`). `sorted_stop` matches it under
  either direction's terms, `pgdt info` tallies it as `constant`, and
  `docs/manual/dump-inspection.md`'s order labels take the word. A
  `CACHE_FORMAT_VERSION` bump. Refused: reading equal exact extremes in
  `column_order`, as the marker proposed, which misses a constant block whose
  bounds were truncated.

## `M233` lands: one function derives a map's diagnostics

`derived_diagnostics` in `crates/pgdt-dump/src/map/tiling.rs` computes the
tiling failure, the TOC-coverage figure and the non-seekable warning from an
index's spans, size and seek table, and is the only caller of the three;
`build_index`, `map_file`, `map_forward`'s EOF exit and the cache load call
it, `map_file` keeping its `carried` identity diagnostics ahead. `KD58` is
struck with its marker, and D19 loses its citation. `map_forward` is a fourth
site the admission did not name, computing two of the three; it takes the
function too. `preamble_only` still adds the warning alone, its map being no
whole one. Test: `map_file_warns_about_a_non_seekable_xz_source_once`, cold
and resumed.

The `KD114`, `KD47` and `KD46` markers named their ledger rows, which
`scripts/repoint.py` reads as provenance in a source comment and fails; each
now says "owned by its out-of-band row", the index line naming the row.

## `M234` lands: a TOC header is read to its line's end

`step` in `crates/pgdt-dump/src/map.rs` hands `parse_toc_header_line` the line
with only its leading whitespace removed, the scanner having already stripped
its terminator, so `COMMENT ON EXTENSION`'s `; Owner: ` parses to a header
with no owner, and an owner or tablespace name ending in whitespace reaches
the span's `TocHeader`, `roles` and `tablespaces` whole. `KD114` is struck
with its marker. `CACHE_FORMAT_VERSION` is 70, every 13–18 fixture holding
such an entry now saving its header. Test:
`a_toc_header_is_read_to_the_end_of_its_line`.
