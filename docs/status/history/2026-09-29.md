## P28's category is its definition, settled with the maintainer

The 28.1 harness NULLed `294276-12-31 23:59:59.999999` (`t_timestamp`, `id`
7), which the spec's list of unrepresentable values omitted. Both it and
`time` `24:00:00` are in the category: the spec's "Scope" and "Facts found
while grilling" carry the values and the evidence, and `KD8` is rewritten to
them. Out would have kept a refusal that depends on which rows a read reached,
the defect the phase exists to remove; clamping `24:00:00` to
`23:59:59.999999` would change a value silently. A nested value holding one
is one, each mode acting on the whole value, and the count walks each leaf by
the column's declared type ("Scope").

The list is held complete by a test, not by review ("Evidence"): an extremes
row for every typed `builtin_scalar` arm, reconciled against the arms so a
new major's base type is forced through it, and validity read off DataFusion's
own display and cast. Slice 28.10 is admitted for it, landing after 28.1 and
before 28.2, carrying the `interval` extremes no fixture held.
