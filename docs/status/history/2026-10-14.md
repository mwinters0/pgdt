# 2026-10-14

## P36.2 split: the seek table is 36.2.1

The spec's slice 2 ([`../../design/roadmap-P36-embedder-api.md`](../../design/roadmap-P36-embedder-api.md),
"Slices, in the order their evidence demands") bundled the arrangement
resolution with making `xz_seek::SeekTable` opaque. These are separate pieces
of work. The arrangement reworks a path that `pgdt`, the provider and their
tests already exercise. The seek table is self-contained, but it reaches into
what the cache persists: `pgdt-dump`'s `CompressionIndex::Xz` serializes the
table, so an opaque wrapper has to keep that format byte for byte, or the
slice owes a `CACHE_FORMAT_VERSION` bump. Each piece needs its own review at
its own confidence (`docs/process.md`, "Slice numbering").

So 36.2 is now the arrangement, landed and ticked
([notes](../../design/roadmap-P36.2-arrangement-notes.md)). 36.2.1 holds the
seek table and `walk_seek_table`'s move to `internal`, the only `pgdt-io`
item in the spec's demotion list that 36.2 did not move. Nothing else changes
order: 36.2.1 comes before 36.3.
