# 2026-10-14

## P36.2 split: the seek table is 36.2.1

The spec's slice 2 ([`../../design/roadmap-P36-embedder-api.md`](../../design/roadmap-P36-embedder-api.md),
"Slices, in the order their evidence demands") bundled the arrangement
resolution with making `xz_seek::SeekTable` opaque. These are separate pieces
of work. The arrangement reworks a path that `pgdt`, the provider and their
tests already exercise. The seek table is self-contained, but it reaches into
what the cache persists: `pgdt-dump`'s `CompressionIndex::Xz` serializes the
table, so an opaque wrapper has to keep that format byte for byte, or the
slice owes a `CACHE_FORMAT_VERSION` bump. Each piece needs its own review at
its own confidence (`docs/process.md`, "Slice numbering").

So 36.2 is now the arrangement, landed and ticked
([notes](../../design/roadmap-P36.2-arrangement-notes.md)). 36.2.1 holds the
seek table and `walk_seek_table`'s move to `internal`, the only `pgdt-io`
item in the spec's demotion list that 36.2 did not move. Nothing else changes
order: 36.2.1 comes before 36.3.

## P36.3 split: the model's interpreted fields are 36.3.1

The spec's slice 3 bundled renames and demotions with three reshapes of
already-tested paths. `ColumnStatistics` and `ColumnBounds` read only through
a view means new constructors for the gatherer (`pgdt-mapping`'s
`gather/column.rs`) and a rewrite of the summary's NULL accounting
(`pgdt-query`'s `summary.rs`), which reads `null_counts` raw. The census as one
field and the database stored once reach every `block.database` read in four
crates, and they bump `CACHE_FORMAT_VERSION`. Each of those needs its own
review at its own confidence (`docs/process.md`, "Slice numbering").

So 36.3 is now the renames, the core's row plumbing in `internal`,
`Diagnostic`'s and `Unrepresentable`'s getters and `StatisticsSizing`, landed
and ticked ([notes](../../design/roadmap-P36.3-core-model-notes.md)). 36.3.1
holds the view-interpreted statistics fields, the census and the database,
with the bump. `instrument` moved nowhere, because an embedder reads it
(`STATUS.md`, "Decisions worth another look"). 36.3.1 comes before 36.4.
