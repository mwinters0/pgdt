## P10 is grilled and sliced

The spec is [`roadmap-P10-row-group-statistics.md`](../../design/roadmap-P10-row-group-statistics.md)
and the checklist is [`../STATUS.md`](../STATUS.md), "P10 progress"; the inbox
is drained there, its `xz-seek` entry refiled to P14's. P20 ("statistics
memory") was allocated in the same grilling and sits directly after P10.

Reversed or narrowed from the sketch, each by the maintainer:

- **The phase is not shaped by one dump**: koji-derived sizing binds nothing.
- **Gathering is on by default**, `--statistics none` opting out; a query never
  gathers.
- **Row groups are byte ranges, not 8192 rows**, concurrent leader pieces not
  knowing global row indices; `SparseRowIndex` is struck.
- **Sortedness is an `Ascending`/`Descending`/`Unsorted` tri-state per block**,
  gathered and stored, where the sketch ranked a flag ahead of min/max.

  advisory; a same-size file rewritten in place prunes on stale statistics.
- **One cache file**; **dictionaries were added** (64 entries, 256 bytes) as a
  statistic, reaching text under any deterministic collation.
- **Resident memory may grow with the dump**, refined by P20, and **no library
  constant moves for it**: before 10.10 no harness `parse` gathers
  (`statistics_flag_problems`), and a bump bills no statistic
  (`Parallelism::fit`) while taking the `reserve` axis's `512m` and `544m`
  24 MiB cells to streaming (`afforded_readers`); slice 10.4.1 is struck.

## A skipped group raises nothing

Reviewed with the maintainer; filed in
[`roadmap-P10-row-group-statistics.md`](../../design/roadmap-P10-row-group-statistics.md),
"Pruning" and "What is gathered, and what is derived".

- **Only ordering, `Decoded` equality and nested terms decode a row**
  (`ResolvedTerm::eval_value`), and a term over a column without bounds or a
  dictionary answers every truth, so a skip stays sound against the server
  whatever such a value holds; what is lost is the unpruned query's error.
- **`KD2` is the one such value `pg_dump` is known to write**, in a nested
  column, which is never keyed while gathering — no per-group mark sees it.
- **Bounds and sortedness are where a wrong answer lives**: a gatherer widening
  only over values that key stores bounds its row lies outside. A dictionary
  holds text, and an entry that does not key already answers every truth.
